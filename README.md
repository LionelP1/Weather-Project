# Weather App 🌤️

## Project Description
This Weather App provides real-time weather information for any city in the world. With features like location suggestions, unit conversion (Celsius to Fahrenheit), and detailed weather statistics, it's designed to deliver an intuitive and user-friendly experience.

## Live Demo
[Weather App Live Demo](https://weather-finder-project.netlify.app/)

## Features
- **Search by City:** Enter a city name to get the current weather information.
- **Location Suggestions:** Get auto-suggested cities based on your input.
- **Weather Details:** Includes temperature, "feels like" temperature, wind speed and direction, pressure, humidity, and visibility.
- **Unit Conversion:** Toggle between Celsius (°C) and Fahrenheit (°F).
- **Responsive Design:** Fully optimized for desktop and mobile devices.

## Data Source
The weather information is retrieved and displayed directly from pre-built static HTML files. This approach ensures offline accessibility and eliminates dependencies on external APIs.
